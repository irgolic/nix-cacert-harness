Source of these files
=====================

Downloaded on 2026-10-23 from https://emudhra.we-have-a-problem.com/ (the page that documents
the eMudhra intermediate incident this campaign responds to), as its chains.zip:

  chains.zip  sha256 7b949956955fc501a30f4d98d2f513d34c0bbbe92e29a968194c96e097ce2345

The 14 *.pem files and README.txt are the contents of chains.zip (chains/), unmodified. They are
public certificates only, leaf first, as served by the site's test hosts; there is no private key
material here (the site's separate proof.zip is not used by this repository).

How the harness uses them
-------------------------

- `bin/ca-static-check --emudhra` (and `bin/ca-check --emudhra`): offline, for every trust store
  found on each side, `openssl verify -attime 1792713600 -purpose sslserver -no-CApath -no-CAstore
  -CAfile <store> -untrusted <chain> <chain>` (README.txt's check, at a fixed time, 2026-10-23
  00:00 UTC, so it keeps working after the leaves expire in May 2027). Java keystores are exported
  to PEM first with `keytool -list -rfc`.
- `bin/ca-live-check`: compares the chain each live host serves with the file of the same name.
- `lib/behave.nix` leaves this directory out of its fixture path.
